# 🐾 구독야옹 (Gudok Yaong)

> **우리 냥이를 위한 프리미엄 수제간식 & 웰니스 맞춤 정기구독 플랫폼**  
> 100% 휴먼그레이드 무첨가 원물 · 집사가 조리하고 냥이가 검증한 식탁

Cloudflare Pages에 1초 만에 무료 배포할 수 있는 초경량·고성능 정적 웹사이트 프로젝트입니다.

---

## ✨ 주요 기능
1. **브론즈 · 실버 · 골드 맞춤 정기구독 플랜**:
   - [고양이 전용] / [냥+멍 함께 키움] 모드 지원
   - [월 1회] / [2주 1회 (-10% 할인)] 주기 선택 지원
   - 플랜 선택 시 냥이 이름, 묘종, 건강 케어(음수량/헤어볼/신장 등), 알레르기 입력 모달 연동
2. **실시간 냥이 시식 일지**:
   - 코숏, 페르시안, 러시안블루, 멍냥공용 등 실제 급여 테스트 일지 탭 전환
3. **냥이 영양 칼럼 & 금기 음식 백과**:
   - 카테고리별 필터링 (금기 음식, 음수량/신장, 헤어볼, 묘종별 팁, 원물 성분)
   - 팝업 모달을 통한 전체 글 읽기 및 연관 맞춤 간식 연동
4. **집사 추천템 큐레이션**:
   - 쿠팡 파트너스, 네이버 쇼핑 커넥트 연동 구조 및 관심 목록 담기 기능
5. **관심 목록 드로어**:
   - 신청한 플랜 및 관심 상품을 실시간 관리하고 비울 수 있는 인터랙티브 모달
6. **SEO & GEO 최적화**:
   - JSON-LD 구조화 데이터, OpenGraph, sitemap.xml, robots.txt 내장
