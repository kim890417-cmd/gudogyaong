# 🐾 구독야옹 (Gudok Yaong) 모바일 어플 프로젝트 가이드

이 폴더는 **구독야옹(9dogyaong)**을 스마트폰 모바일 어플(Android 네이티브 앱 및 PWA)로 사용하고 빌드할 수 있도록 제작된 프로젝트입니다.

---

## 📱 [방법 1] 스마트폰에서 1초 만에 앱으로 설치하기 (가장 추천! ⭐⭐⭐⭐⭐)

별도의 복잡한 개발 프로그램 없이, **내 스마트폰에서 지금 즉시 주소창 없는 진짜 어플**로 설치하여 사용하는 방법입니다.

### 🤖 갤럭시 / 안드로이드 폰에서 설치하기:
1. 스마트폰 브라우저(크롬 또는 삼성 인터넷)를 엽니다.
2. 배포된 구독야옹 주소 **`https://gudogyaong.pages.dev/`** 에 접속합니다.
3. 브라우저 우측 상단 메뉴(점 세 개 `⋮` 또는 삼선 `≡`)를 누릅니다.
4. **[앱 설치]** 또는 **[홈 화면에 추가]** 버튼을 터치합니다.
5. 스마트폰 바탕화면에 **귀여운 구독야옹 고양이 앱 아이콘**이 생성됩니다!
   > 💡 실행해 보시면 브라우저 주소창이 싹 사라지고, 일반 앱과 똑같이 전체 화면으로 부드럽게 작동합니다.

### 🍎 아이폰 (iOS)에서 설치하기:
1. 아이폰의 **Safari(사파리)** 브라우저를 엽니다.
2. **`https://gudogyaong.pages.dev/`** 에 접속합니다.
3. 화면 하단 중앙의 **[공유 버튼 (네모 위로 화살표 아이콘)]**을 누릅니다.
4. 메뉴에서 스크롤을 내려 **[홈 화면에 추가]**를 선택합니다.
5. 아이폰 홈 화면에 '구독야옹' 정식 앱 아이콘이 생성됩니다!

---

## 💻 [방법 2] 안드로이드 스튜디오로 실제 APK 파일 빌드하기 (스토어 출시용)

이 폴더의 `android` 디렉토리는 **Android Studio(안드로이드 스튜디오)**에서 바로 열어서 실제 `.apk` 파일로 만들 수 있는 정식 네이티브 앱 프로젝트입니다.

### 📁 안드로이드 프로젝트 구조:
- **`android/app/src/main/java/com/gudogyaong/app/MainActivity.kt`**:
  - 스마트폰 뒤로가기 버튼 완벽 처리 (웹 뒤로가기 및 2회 연속 터치 시 종료 안내)
  - 당겨서 새로고침 (`SwipeRefreshLayout`)
  - 카카오톡 상담, 전화 걸기 등 외부 앱 인텐트 자동 연결
  - 상단 세련된 오렌지빛 로딩 프로그레스바
- **`android/app/src/main/AndroidManifest.xml`**:
  - 인터넷 및 네트워크 권한 설정
  - 딥링크(`gudogyaong.pages.dev` 링크 터치 시 앱으로 바로 열기) 지원
- **`android/app/src/main/res/`**:
  - 구독야옹 고양이 벡터 앱 아이콘 (`ic_launcher.xml`)
  - 테마 색상 (따뜻한 크림 `#FAF7F2` 및 테라코타 오렌지 `#E06D3B`)

### 🛠️ APK 파일 빌드 방법:
1. 컴퓨터에서 **Android Studio** 프로그램을 실행합니다.
2. [Open]을 누르고 **`C:\Users\sadase\Desktop\구독야옹\어플\android`** 폴더를 선택하여 엽니다.
3. Gradle 동기화(Sync)가 완료되면 상단 메뉴에서:
   - **[Build] ➡️ [Build Bundle(s) / APK(s)] ➡️ [Build APK(s)]** 클릭!
4. 빌드가 끝나면 우측 하단에 알림창이 뜨며, `locate`를 클릭하면 생성된 **`app-debug.apk`** 파일을 바로 확인할 수 있습니다.
5. 이 APK 파일을 스마트폰으로 전송(카톡/이메일 등)하여 설치하시면 진짜 안드로이드 앱으로 스마트폰에 영구 설치됩니다!
