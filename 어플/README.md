# 🐾 구독야옹 (9dogyaong) - 반려동물 품종 백과 & 건강·식단 관리 집사 앱 (Flutter)

> **"고양이·강아지 품종 백과 + 건강·식단 관리 집사 앱"**  
> 쇼핑몰 앱이 아닌, 우리 반려동물의 매일매일 건강과 식습관을 케어하는 따뜻한 집사 전용 모바일 앱입니다.

---

## 📱 핵심 기능 (하단 5개 탭)

1. **탭 1. 홈 (우리 아이 오늘의 대시보드)**:
   - 상단 반려동물 프로필 전환 (고양이/강아지, 이름, 품종, 나이, 체중, 중성화 여부, 건강 고민 태그)
   - 기본 샘플 데이터: `루나 (코리안숏헤어, 4세, 4.2kg)`
   - 체중 맞춤형 오늘의 권장 음수량 계산 및 원터치 추가 (`+20ml`, `+50ml`, `+100ml`, `직접 입력`)
   - 보존료 0% 수제간식 개봉일 · 유통기한 D-Day 배지 (냉장 7일, 냉동 30일)
   - 오늘의 냥이/멍이 맞춤 영양 케어 팁 카드 (탭 시 모달 상세)

2. **탭 2. 기록 (데일리 건강 트래커 & 병원 리포트)**:
   - 원터치 일일 체크: 소변(감자), 대변(맛동산), 구토/헤어볼 횟수 카운터
   - 최근 7일간 음수량 및 배변 추이 막대 그래프
   - 동물병원 제출용 '최근 7일 요약' 모달 & 원클릭 클립보드 텍스트 복사

3. **탭 3. 백과 · 식단 (도감 & 집사 도구 5종)**:
   - **품종별 동물 백과사전 (22종 내장)**:
     - 고양이 12종: 코숏, 러블, 브숏, 스코티시폴드, 페르시안, 랙돌, 아메숏, 먼치킨, 샴, 노르웨이숲, 뱅갈, 터키시앙고라
     - 강아지 10종: 말티즈, 푸들, 포메라니안, 비숑, 시츄, 웰시코기, 리트리버, 진돗개, 치와와, 닥스훈트
     - 성격, 취약 질환, 추천 원물 및 급여 형태, '내 아이로 바로 등록하기' 지원
   - **하루 칼로리 & 음수량 계산기**: RER, DER, 목표 음수량 즉시 계산 및 맞춤 플랜 조용히 추천
   - **사료 건물 기준(DM) 분석기**: 수분을 제외한 실제 조단백·조지방·탄수화물 비율 분석
   - **먹어도 되나요? 금기 음식 검색기**: 20개 이상 음식 검색, 3단계 배지 (절대 금기/소량 주의/안전)
   - **원물 시식 도감**: 닭가슴살, 연어, 오리 등 원물별 기호성(잘 먹음/보통/거부/알레르기) 체크 및 메모

4. **탭 4. 놀이 (참여형 미니 기능)**:
   - 냥이 화면 터치 놀이 2종 (움직이는 물고기 터치 / 빨간 레이저 포인트 잡기)
   - 목욕/이동 전후 안정 케어 시각 타이머 & 집사용 진정 팁

5. **탭 5. 스토어 (구독야옹 — 전체의 일부분)**:
   - 시식 도감에서 알레르기 체크된 원물 상단 배지 안내
   - 맞춤 정기구독 플랜 (브론즈, 실버, 골드)
   - 집사 꿀템 큐레이션 및 관심 목록
   - 공식 웹페이지(`https://gudogyaong.pages.dev/`) 및 카카오톡 채널 연동 (`url_launcher`)

## 🛠️ 실행 및 빌드 방법 (Flutter)

```bash
# 1. 의존성 패키지 설치
flutter pub get

# 2. 코드 분석 및 검사
flutter analyze

# 3. 디버그 모드로 앱 실행
flutter run

# 4. 안드로이드 APK 파일 빌드
flutter build apk --release
```
생성된 APK 파일은 `build/app/outputs/flutter-apk/app-release.apk`에 위치합니다.
